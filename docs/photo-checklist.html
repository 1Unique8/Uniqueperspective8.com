Provenance Ethics

Studio list, not a shop page

Photos the provenance pages still need.

Each area page looks for one hero file in images/. Upload through GitHub. Do not send binary files through the text API.

How to shoot
Daylight or a north window. Stones on a plain surface, or the roadcut itself if the frame cannot be mistaken for a mine. No claim posts. No MINFILE names in the caption or the file name. Long edge about 1600 px. Keep the file under 400 KB. JPEG.
How to upload
Open the repo images/ folder on GitHub, drop the file with the exact name below, commit to main. Pages will pick it up on rebuild.
Never in the frame
Vault. Dusty Mac. Claim markers. Mine buildings. Grade numbers. A caption that says “from the mine.”

Optional supporting shots

Group tray
One photograph of the stones from that code on a white or linen ground. Same file can be the hero if it reads as stones, not as a mine tour.
Roadcut context
Only if the photograph is clearly a public highway cut or pathway margin. Keep people, vehicles, and signage that name a mine out of the frame.
FMC card
Internal Vein Ledger only. Do not put the certificate image on a public provenance page unless you decide that later.
Specimen stills
PEN 001–007 already use Drive thumbnails on specimens.html. Leave those until you migrate the cabinet images into images/.
