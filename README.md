## WordPress Theme (New!)

We've added a ready-to-import **WordPress theme** in the `uniqueperspective8-theme/` folder.

### How to Import as WordPress Theme

1. Download or clone this repository.
2. Zip the entire `uniqueperspective8-theme` folder (it should contain `style.css`, `functions.php`, `index.php`, `header.php`, `footer.php`).
3. In your WordPress admin, go to **Appearance > Themes > Add New > Upload Theme**.
4. Upload the zip file and activate the theme.

### Theme Features
- Elegant dark luxury design matching Unique Perspective 8 branding (gold accents, Cormorant Garamond + Inter fonts)
- Full **WooCommerce** support (perfect for your jewelry & mineral shop)
- Custom logo, menus, featured images
- Responsive and mobile-friendly
- Brand storytelling baked into the homepage

### Next Steps / Customization
- Add your logo via Customizer
- Create pages for About, Shop, Contact, etc. (or use existing static content as starting point)
- Set up WooCommerce and import your products
- Expand with child theme for further customization
- Consider moving blog content into WordPress posts

The theme is a solid foundation. You can continue developing it here in GitHub or connect it to your hosting (e.g., via GitHub Actions for deployment).

**Tip:** For a hybrid approach, you can keep the static site on GitHub Pages while running the WordPress version on your main domain or a subdomain.
