## Education Hub

Canonical public URL: `https://uniqueperspective8.com/education/`

WordPress (when the theme in `uniqueperspective8-theme/` is active):

1. Create a page titled **Education Hub**.
2. Set the permalink slug to `education`.
3. In Page Attributes, choose template **Education Hub** (`page-education.php`).
4. Optional: create a second page with slug `knowledge` and template **Knowledge Hub** so `/knowledge` 301s to `/education`.
5. Create a post category `education` if you want journal posts to appear on the hub.
