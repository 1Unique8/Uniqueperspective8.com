# Unique Perspective 8 Telegram Bot

Starter bot for the @UniqueP8 channel and shop.

## Setup

1. Get a Bot Token from @BotFather
2. Set environment variable:
   ```
   export BOT_TOKEN=your_token_here
   ```
3. Install and run:
   ```
   cd telegram-bot
   npm install
   npm start
   ```

## Commands

- /start - Welcome message
- /products - Link to channel
- /shop - Website shop
- /help - List commands
- /announce - Post to channel (bot must be admin)

## Channel

https://t.me/UniqueP8

Make sure the bot is added as admin with Post Messages permission.
