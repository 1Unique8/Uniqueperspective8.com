Catalogue rule

Name only what the tests earned.

Every specimen listing carries one visible tag: Confirmed, Probable, or Field ID only. A definitive mineral name may appear only beside Confirmed.

The three tags

TagWhat it meansGrep token
ConfirmedThe five-test protocol was run and logged: hardness, streak, LED, 365 nm UV, acid. The mineral name is allowed in public.data-id-confidence="confirmed"
ProbableA lithologic working name is locked from fabric or habit. The protocol is not logged. No mineral species in the title.data-id-confidence="probable"
Field ID onlyColor, place, or a field word. Type may still be pending.data-id-confidence="field-id-only"

Confirmed is not “did not obviously fail.” It is “the five tests were written down.” Until that row exists, grep for data-id-confidence="confirmed" should return nothing in the cabinet.
