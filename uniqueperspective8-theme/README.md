# Unique Perspective 8 — Collector’s Folio WordPress Theme

This theme is a self-contained WordPress and WooCommerce implementation of the Collector’s Folio luxury redesign. It includes the required field-study imagery and compass mark under `assets/luxury/`.

## Installation

Create a ZIP whose root folder is `uniqueperspective8-theme`, then upload it in **WordPress Admin → Appearance → Themes → Add New → Upload Theme**. Activate the theme and set the homepage display to the latest posts or assign a static page using this template. Assign a menu to **Primary Menu**; if no menu is assigned, the theme safely shows anchor navigation.

WooCommerce support is included. When published products exist, the collection section renders up to three real products; otherwise, it retains neutral collection messaging without claiming products that are not in the catalog.
